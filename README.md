# MisGe — поиск лекарств по аптекам Грузии

Телеграм-бот: пользователь пишет название препарата — бот отвечает, в каких аптеках он
есть и по какой цене. Источник данных — [mis.ge](http://www.mis.ge), официального API у
сайта нет, всё берётся из его же HTML-форм.

## Состояние

| Шаг | Что | Статус |
|-----|-----|--------|
| 1 | HTTP-клиент, парсер, консольный прототип | готово |
| 3 | Транслитерация ru→lat, ka→ru и ka→lat, подбор запроса | готово |
| 4 | Каркас бота на aiogram | готово |
| 2 | Справочники городов и районов в SQLite | — |
| 5 | Кеш и состояние поверх SQLite | карточки аптек и выбранный город — есть, кеш остатков — нет |
| — | Алерт администратору при поломке парсера | готово |
| 6 | «Следить за препаратом» + APScheduler | — |
| 7 | Деплой | — |

## Установка

```
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements-dev.txt
```

## Запуск бота

Возьмите токен у [@BotFather](https://t.me/BotFather), скопируйте `.env.example`
в `.env`, подставьте токен — и:

```
python -m misbot.bot
```

Без токена бот не стартует и говорит, чего именно ему не хватает.

Что умеет: принимает название препарата на любом из трёх алфавитов, показывает
список найденных форм выпуска с листанием, по нажатию на номер — аптеки с ценами.
`/city` выбирает город, `/about` рассказывает про источник и даты, `/help` — как
пользоваться, `/id` показывает chat id (нужен для настройки алертов).

`/stats` показывает счётчики — но только владельцу бота. Кто владелец, задаётся
переменной `MISGE_ADMIN_ID` (свой telegram id подскажет команда `/id` или
[@userinfobot](https://t.me/userinfobot)); пока она не задана, команда молчит для
всех. Остальным она не отвечает вовсе — не «нельзя», а ничего, иначе само
существование команды видно любому, кто её наберёт. В `/help` её тоже нет.

Выбранный город хранится в SQLite и переживает перезапуск: на сервере он бывает
часто (деплой, перезагрузка), а человек, выбравший Батуми, не должен вдруг снова
получать Тбилиси. Последняя выдача поиска остаётся в памяти — она нужна только
для листания и после перезапуска бессмысленна.

Один пользователь может занимать не больше одного запроса к mis.ge одновременно.

## Когда что-то ломается

Бот живёт на сервере, и логи там никто не читает. Если mis.ge поменяет вёрстку,
парсер начнёт падать, пользователь увидит вежливое «скоро починим» — и на этом
всё закончится, потому что «скоро» никому не поручено.

Поэтому о поломке разбора бот пишет сам — тому же владельцу из `MISGE_ADMIN_ID`.
При `ParseError` придёт сообщение с местом поломки и подсказкой снять свежие
фикстуры. Одинаковые поломки шлются не чаще раза в час, иначе при сломанном
сайте это будет сотня сообщений подряд. Текст запроса пользователя в алерт не
попадает — мы их не сохраняем.

Переменная не задана — бот молчит и работает как раньше.

## Консольный прототип

```
python -m misbot.cli нурофен                      # что вообще есть с таким названием
python -m misbot.cli нурофен --pick 1 --city 1    # где купить в Тбилиси и почём
python -m misbot.cli --locations                  # id городов, районов, микрорайонов
python -m misbot.cli нурофен --georgian           # не переводить вывод в кириллицу
python -m misbot.cli нурофен --save-html tests/fixtures   # снять свежие фикстуры
```

Запрос принимается на любом из трёх алфавитов, вывод по умолчанию переводится
в кириллицу.

## Архитектура

Четыре слоя, парсинг намеренно отделён от логики бота:

* `misbot/mis_client.py` — только HTTP: `search()` и `pharmacies()`, отдают сырой HTML.
  Здесь же rate-limit (1 запрос в секунду) и ретраи.
* `misbot/parser.py` — HTML → `Medicine` / `Stock` / `Locations`. Самая хрупкая часть,
  падает с `ParseError`, если вёрстка поехала.
* `misbot/translit.py` — грузиница → кириллица для вывода и кириллица → латиница
  для запроса.
* `misbot/search.py` — подбор написания: решает, что и в каком порядке спросить
  у сайта, и останавливается на первом варианте, который что-то нашёл.
* `misbot/models.py` — dataclasses, ничего не знают ни про HTTP, ни про HTML.
* `misbot/bot.py` — aiogram: хендлеры, клавиатуры, состояние пользователя.
* `misbot/formatting.py` — все тексты, которые видит пользователь.
* `misbot/locations.py` — справочник городов с запасным списком на случай, если
  сайт лежит.
* `misbot/pharmacies.py` — карточки аптек: сперва кеш, чего нет — с сайта.
* `misbot/landmarks.py` — перевод ориентиров на русский по словарю.
* `misbot/forms.py` — перевод карточки препарата: название и форма выпуска,
  страна, производитель, МНН, режим отпуска.
* `misbot/cache.py` — SQLite-кеш карточек аптек.
* `misbot/stats.py` — счётчики обращений в том же SQLite.
* `misbot/user_store.py` — выбранный город в SQLite, переживает перезапуск.
* `misbot/alerts.py` — сообщения владельцу, когда ломается разбор.
* `misbot/config.py` — настройки из окружения или `.env`.
* `misbot/cli.py` — консольный прототип, он же инструмент для снятия фикстур.

Хендлеры регистрируются списком в `build_router()`, а не декораторами: декоратор
привязывает их к одному общему `Router` на модуль, а такой роутер нельзя
подключить к двум диспетчерам — тесты начинают мешать друг другу.

## Как устроен сайт

```
GET  /mis_mobiluri.mis?c=1&d=0&user_name=nurofen
POST /mis_aftiaqebi.mis   qalaqi=1&ubani=0&qveubani=0&<ХЕШ_ПРЕПАРАТА>=on
```

`c=1` — поиск по началу слова, `d=1` — по международному названию. Хеш препарата —
имя чекбокса в выдаче поиска, он стабилен между запросами, поэтому каталог можно
кешировать у себя.

**Сайт ищет по латинскому международному названию, а не по грузинскому.** Это не
очевидно, потому что и выдача, и сам сайт целиком на грузинском, но проверено:
`diclofenac` находит 64 препарата, а `diklofenak` — ни одного; `citramon` — 23,
`tsitramon` — ноль; `heparin` — 37, `geparin` — ноль. Отсюда всё устройство
`translit.py`: русское название надо превратить не в грузинскую фонетику, а в
латинское написание. Ещё сайт требует минимум три буквы и сравнивает по началу
строки — последнее оказалось спасением, см. ниже.

Ловушки, на которые уже наступили:

* Сайт работает **только по HTTP** — порт 443 мёртв. Запросы пользователей идут
  открытым текстом, поэтому их нельзя логировать; это же надо написать в политике
  приватности бота.
* Цена `0.00` означает «нет данных», а не «бесплатно». Парсер отдаёт `None`.
* Срок годности `1900-01-01` — тоже заглушка, парсер отдаёт `None`.
* Дата обновления остатка у части аптек отстаёт на год и больше. Показывать её
  пользователю обязательно, `Stock.is_stale` помечает всё старше двух месяцев.
* В POST по аптекам можно передать не больше **13 хешей препаратов**. На
  четырнадцатом сайт молча отдаёт пустую таблицу — не ошибку, а именно пустой
  результат, неотличимый от «нигде нет». `MisClient.pharmacies` не даёт
  передать больше.
* Когда ничего не нашлось, сайт рисует таблицу с пустым `<tbody>`, а не убирает её.
  Отличить «в этом городе нет» от «парсер сломался» можно только по подписи
  «მოიძებნა N …» под таблицей. На странице аптек таких подписей две — сколько
  наименований и сколько аптек; нужна вторая.
* Весь контент на грузинском.

## Транслитерация

Наружу всё просто: грузиница → кириллица, побуквенная замена по алфавиту плюс
словарь для того, у чего есть нормальное русское имя, — городов, районов и слов
из расписаний (иначе ფოთი стало бы «Потхи», а კვ/დასვენება — «кв/дасвенеба»).
Словарь применяется по подстроке с проверкой границ: в расписании соседом справа
бывает слеш, а не пробел, но при этом короткий ключ не должен влезать внутрь
длинного слова. Адреса через транслитерацию не проходят вовсе — см. выше.

Рядом живёт вторая наружная замена — грузиница → латиница (`ka_to_latin()`),
по национальной системе романизации. Она нужна названиям аптек; подробности —
в разделе про адреса.

Внутрь сложнее. Русские названия лекарств — сами транслитерация латинских, но
неоднозначная: «диклофенак» это `diclofenac`, а «кетонал» — `ketonal`, хотя «к»
одна и та же. Поэтому `ru_to_latin_candidates()` отдаёт не один вариант, а
ранжированный список, где у каждой замены своя цена: `г→g` дешевле, чем `г→h`
(gentamicin против heparin), `ф→f` дешевле `ф→ph` (ibuprofen против morphine).
`search.py` перебирает кандидатов по очереди и останавливается на первом, который
что-то нашёл.

Если не помог ни один — запрос обрубается до префикса. Хвост русского названия
часто расходится с латинским («цефтриаксон» → `ceftriaxone`), а поиск идёт по
началу строки, так что `ceftria` находит то, чего не нашёл `ceftriakson`.
Последняя попытка — поиск по МНН.

Бюджет — восемь обращений к сайту на запрос: при лимите 1 rps каждый промах
стоит секунду. Дальше это прикроет кеш (шаг 5).

Как проверялось:

```
python tools/check_translit.py --verbose
```

45 русских названий против живого сайта: 45 из 45, из них 42 — прямым подбором
написания, 3 — через обрубленный префикс. Прогон занимает около минуты.
Юнит-тесты сети не требуют, ожидания в них сверены с этим прогоном.


Сеть не нужна: парсер и подбор запроса проверяются на сохранённых страницах в

## Адреса аптек

В выдаче наличия адреса нет — только город, район и микрорайон. Адрес, вывеска,
часы работы, телефон и точка на карте лежат в отдельной карточке
`mis_aftiaqi.mis?<id>=a`, то есть один запрос на аптеку. При лимите 1 rps
показать адреса у восьми аптек — это восемь секунд ожидания, и так каждый раз.

Поэтому две вещи. Первая — карточки кешируются в SQLite (`cache.py`) на 90 дней:
аптеки переезжают редко, так что запрос платится один раз за всё время. Вторая —
сообщение уходит сразу с ценами и тем, что уже есть в кеше, а когда недостающие
карточки доедут, оно правится на месте. На холодном кеше это выглядит как
«цены сразу, адреса через пару секунд», на тёплом правки нет вовсе.

Замер на консольном прототипе: холодный прогон 4,4 с, повторный — 1,4 с.

Адрес с сайта приходит вместе с городом и районом («Тбилиси Сабуртало M мед.
институт ул. такая-то 6»), и они обрезаются — иначе половина строки уходит на
то, что и так написано рядом.

**Что переводится, а что нет.** Всё, что человек предъявляет на месте, остаётся
на грузинском: улица с номером дома и ориентир. Адрес показывают водителю,
ориентир — прохожему; транслит и латиница тут только мешают.

Кириллицей идёт то, что читает сам пользователь: город и район рядом с адресом,
часы работы, названия препаратов.

Название аптеки показывается дважды: сначала латиницей, следом в скобках
оригинал — «Pharmagidi Gea (ფარმაგიდი გეა)». Латиница читается и произносится
всеми, на ней же аптечные сети ищутся в картах; оригинал нужен, чтобы сличить с
надписью на двери. Если название и так латиницей («PSP»), скобок нет — они
повторили бы то же самое. Романизация — национальная система 2002 года, та же,
что на дорожных знаках, плюс ручной словарь на сети и слова, где система
промахивается: ფ по ней читается как `p`, так что «ფარმა-» без словаря стало бы
«Parma-».

Ориентир тоже показывается дважды, переводом и оригиналом. Перевод нужен, чтобы
понять, куда идти; оригинал — чтобы показать прохожему.

## Перевод названий препаратов

Названия на сайте устроены одинаково:

```
[бренд] [дозировка] [форма выпуска] [упаковка] #[штук]
ნუროფენ ფორტე 400მგ შემოგარსული აბი - #48
```

Порядок слов совпадает с русским, поэтому, в отличие от ориентиров, переставлять
ничего не надо — хватает словаря словосочетаний в `forms.py`. Бренд остаётся
транслитом: это имя собственное, переводить его нечем.

Три вещи, которые словарь не решает сам:

* **Единицы приклеены к числу** — `400მგ`, `100სე/მლ`. Их разбирает отдельное
  правило: после числа ставится пробел, после слеша — нет.
* **Грузинский вешает на заимствования именительное `-ი`**, из-за чего выходило
  «Парацетамоли». У слов длиннее трёх букв оно отбрасывается.
* **`#48` в конце** — это не номер, а количество в упаковке, поэтому
  превращается в «48 шт.».

Остальные поля карточки делятся на два вида. **Страны и режим отпуска** —
конечные списки (43 и 4 варианта), переводятся целиком. **Производители и МНН** —
сотни имён собственных, их только причёсываем: отбрасываем грузинское окончание
и ставим заглавные. У компаний с большой буквы каждое слово, у действующих
веществ только первое — «Цинк инсулин (свиной монокомпонентный)» это описание,
а не имя.

Отдельный словарь нужен химии: побуквенно `ჰიდროქლოროთიაზიდი` даёт
«Хидроклоротиазид», потому что грузинское `ჰ` в заимствованиях из латыни — это
русское «г», а `ქლ` — «хл». Тот же словарь подключён и к названиям препаратов:
`ლიდოკაინის ჰიდროქლორიდი` → «Лидокаин гидрохлорид».

Словари проверяются на корпусах в `tests/fixtures`: 337 названий, 43 страны,
182 производителя, 40 МНН, 4 режима отпуска. Для названий тест ищет следы вроде
«аби», «фхвнили» или «саинекцио» — если такой найдётся, значит форма выпуска не
попала в словарь; для остальных полей достаточно проверки, что грузинских букв
в переводе не осталось.

## Перевод ориентиров

Ориентиры устроены однообразно: `[что-то в родительном падеже] + [слово места]`.
«ხეჩინაშვილის კლინიკის გვერდით» — это `[Хечинашвили][клиники][рядом]`. Слово места
в грузинском стоит последним, в русском — первым, так что мало заменить слова,
надо ещё переставить. Этим занимается `landmarks.py`:

1. режет фразу по запятым и скобкам;
2. отрывает от конца слово места и превращает его в русский предлог;
3. остальное делит на знакомое (переводим по словарю) и незнакомое (имена
   собственные — транслитерируем, отбросив грузинское окончание родительного,
   иначе выходит «Хечинашвилис»);
4. собирает по-русски: предлог, прилагательные, существительные, имена.

Падежей и согласований нет: все предлоги в словаре подобраны так, чтобы
управлять родительным — поэтому «возле», а не «рядом с» (творительный), и
«в сторону», а не «по направлению к» (дательный). Тогда каждому существительному
хватает одной формы.

Словарь заведомо неполон, и это нормально: незнакомое проходит насквозь как имя
собственное, а оригинал всё равно рядом. Проверяется он на корпусе из 24 живых
ориентиров в `tests/fixtures/landmarks.txt` — тест требует, чтобы в переводе не
осталось ни одной грузинской буквы. Появятся новые формулировки — корпус
дополняется, дырки видно сразу.

## Приватность

Тексты запросов не логируются. Мест, где они могли бы утечь, два, и оба закрыты:
`search.py` пишет их только на уровне DEBUG, а `httpx` на INFO печатает URL
целиком — вместе с `user_name`, — поэтому его логгер приглушён до WARNING.
Включать `MISGE_LOG_LEVEL=DEBUG` на проде не стоит.

Сам сайт-источник работает без шифрования, так что до mis.ge название препарата
всё равно идёт открытым текстом. Это сказано пользователю в `/about`.

**Статистика** (`stats.py`) устроена так, чтобы это обещание не нарушать. В базе
лежат только числа по дням: сколько было запросов, сколько нашлось, сколько раз
смотрели аптеки. Текстов запросов там нет. Пользователи считаются по хешу
`sha256(соль + telegram id)` — сам id не хранится, а соль генерируется при первом
запуске и живёт в той же базе, так что и по хешу восстановить id перебором
(идентификаторов всего-то миллиарды) не выйдет, не зная соли. Что именно
считается, сказано пользователю в `/about`.

## Этика к источнику

Не больше одного запроса в секунду, в `User-Agent` — контакт для связи. Перед запуском
бота написать на info@mis.ge и предупредить. Ссылку на источник ставить в каждом ответе.
Бот показывает цены и наличие и не даёт медицинских советов — дисклеймер обязателен.
